\## 📚 Quantum Computing Laboratories



A collection of \*\*24 Jupyter Notebook experiments\*\* organized into three quantum computing laboratory courses.



| No. | Course | Experiments | Laboratory Manual |

|---|---|---|---|

| 01 | \[Introduction to Quantum Computing](01-Introduction-to-Quantum-Computing/README.md) | 8 | \[View Manual](01-Introduction-to-Quantum-Computing/Lab-Manual.pdf) |

Each course includes a laboratory manual, an experiment index, and eight Jupyter notebooks containing Python implementations and simulation results.



\### Topics Covered



\- Quantum states, statevectors, and measurement

\- Quantum gates and multi-qubit circuits

\- Quantum entanglement and teleportation

\- Deutsch-Jozsa and Bernstein-Vazirani algorithms

\- Simon's algorithm

\- Grover's search algorithm

\- Quantum Fourier Transform and phase estimation

\- Shor's algorithm — simplified factoring demonstration

\- Quantum kernel Support Vector Machine

\- BB84 quantum key distribution simulation

\## 🚀 Getting Started



\### 1. Clone the Repository



```bash

git clone https://github.com/samyakdekate21/Quantum-Learning.git

cd Quantum-Learning

```



\### 2. Install Dependencies



Ensure Python and pip are installed, then run:



```bash

python -m pip install qiskit qiskit-aer numpy matplotlib scikit-learn jupyter pylatexenc

```



\### 3. Launch Jupyter Notebook



```bash

jupyter notebook

```



Navigate to any laboratory course, open its `notebooks` folder, and select an experiment to explore or execute.



\*\*Note:\*\* The laboratory experiments primarily use classical quantum circuit simulators and do not require physical quantum hardware.
